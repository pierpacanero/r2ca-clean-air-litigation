# Clean Air Litigation Database

Static website of the Clean Air Litigation Database, developed within [R2CA — The Right to Clean Air](https://hubtolaw.it/projects/r2ca-the-right-to-clean-air/), a research project of the University of Turin. Judicial decisions and pending proceedings on air quality, presented through original abstracts, navigable from an interactive world map.

## How it works

- `site/` — the static shell of the website (HTML, CSS, JS, world map data, `/admin` panel). No build tooling beyond the merge step below; libraries (d3, topojson, Decap CMS) are loaded from public CDNs.
- `cases/` — the dataset: one JSON file per case. **This is the only folder editors touch.**
- `scripts/build.py` — merges `cases/*.json` into `data/cases.json`, validates every entry and copies `site/` to `_site/`. A validation error aborts the build, so a broken entry can never replace the live dataset.
- `.github/workflows/deploy.yml` — on every push to `main`, builds and deploys `_site/` to GitHub Pages.

So: editing or adding a case (directly or through the CMS) → commit on `main` → the site rebuilds and republishes itself in about a minute.

## Editing content

Two ways:

1. **Content manager (recommended for editors):** the site serves [Decap CMS](https://decapcms.org) at `/admin/` — a form-based interface, one entry per case, no JSON to touch. Login is handled by [DecapBridge](https://decapbridge.com) (email invitations, no GitHub account needed). See *Activating the CMS* below.
2. **Directly on GitHub:** edit or add a file in `cases/` from the GitHub web interface. The filename must be `<slug>.json` and match the `slug` field.

The editors' guide (in Italian) is in [`docs/guida-redazione.md`](docs/guida-redazione.md); the country-code table for the map is in [`docs/codici-paesi.md`](docs/codici-paesi.md).

## Activating the CMS (once, ~5 minutes)

1. Create a free account on [decapbridge.com](https://decapbridge.com) and add a *Site*.
2. Connect this repository (`<owner>/<repo>`) with a fine-grained GitHub token — permissions: *Contents: read and write* ([github.com/settings/tokens](https://github.com/settings/tokens)).
3. Set the CMS URL to `https://<owner>.github.io/<repo>/admin/index.html`.
4. Replace the `backend` block at the top of [`site/admin/config.yml`](site/admin/config.yml) with the one generated by DecapBridge (leave everything from `media_folder` down unchanged), commit.
5. Invite the editors by email from the DecapBridge dashboard.

## Local build

```bash
python3 scripts/build.py
python3 -m http.server 8766 -d _site
```
